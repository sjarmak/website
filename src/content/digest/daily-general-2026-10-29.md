Copilot Fusion, the model router GitHub announced yesterday, costs $5.59 per task on Artificial Analysis's Coding Agent Index against $11.42 for Claude Opus 5.5 running in Claude Code, according to the evaluator figures in [AINews' recap](https://link.mail.beehiiv.com/ss/c/u001.ph_QWNSUqNc4t8_ksAzZPtOnCr0U3hlVEzELSqUWNMYAG3WNicdimvhEF6_um4I3iyNlzidD7BXPMOd-PjPZXDdKzRmXcyzbmvZEBZeqr26kmRFEIUmvIe1g3B2uLkPxZAIeped_1ZELXHDDPRPnCJrCe-vn4AtlYh3ZxsyKi7jmuTR2YKz29OrsC0Pe3gnhStUDdht4bvZ2BDildvm2x2v5ZcUOWvb0thNiHVzED5T3MHNTtAxhL2mIjMrKPmxXGgiQf7DX-rreGaeEDNmhOvILzbV7EJfvXwq4Yua-yblAcFWixSw_tVpWZy3ZUVVdyXC3s7LL9bdabTY8cIOeO454VQMxk2cjSW4bgShEWMbrHNqPw1ujmGF8Tyl74fmkkN1bRgPZawXZchCp9hc-mchV0OXASMxlBxkrs5weEEWpsBqWRCU-bsJdetlDtckDKhJ-Q63LwFmNKQxMzIyU0k7sF3-mbt0yiBsYREL85SlKE7YVTh9g-qc_OcO-Kku8PgJpqCOVW91bjfs_5g2QjysI_HOkgHPOBc80EJvsQVVT3sMjazaCpyXbZulyV3ffOb2OT34ip12HOF9-v1-2xEOVn4oOMhIKPwrnGWAwWYX0tdJbqWDC7kSoWhhWrCwMW2HGU-kfX9wrNyUgFZIm5cRz6KlS8fo6aOT7um3I3fauZx8XMGbP_RRas0HqIUi7ebRqG-kB2z8F4B28y27dKQ/4va/sia1ZUqnT6WH4MUNZRGl1Q/h0/h001.kfM3etxS4Vgr6MLCKZXxGL3OXsaax4MdjE3Lt9PwhaQ), which also has Fusion leading Terminal-Bench 4.0 at 71. GitHub's own claim is that Fusion Max lands within two points of Opus 5.5 Max on that index at half the cost and 40% less time per task. Fusion is the part of [GitHub Universe 2026](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/) with numbers attached: it judges each task by how much reasoning, code generation, debugging and tool use it needs, then runs it on one or more models from Anthropic and OpenAI. A separate changelog entry adds local models to the pool it can choose from.

The rest of Jay Parikh's keynote post describes a Copilot organized around agent sessions. The new Copilot app is an agent-first surface that runs from issue to merge and also covers specs, design discussions and telemetry. Copilot projects run agent work across several repositories in parallel managed sessions, and session continuity lets a single session move between the GitHub app, VS Code, the CLI and the web. Copilot automations, cloud workflows triggered by events or schedules, now learn from how their runs turned out and propose improvements to themselves for a human to approve. The change budget holders will notice first is commercial: GitHub Enterprise customers get every Copilot feature without a separate subscription and pay for the AI credits they use, through sales today and self-serve soon. Underneath all of it, GitHub says it added 4 million CPU cores, 160 PB of storage and 50 Tb/s of network capacity this year, and its multi-region Azure migration finishes early next year.

Parikh predicts that all software written to date "will amount to less than 1% of the software we'll write in the next five years," and the Octoverse report shows the slope he is extrapolating from. In [Simon Willison's notes from the event](https://simonwillison.net/2026/Oct/28/github-octoverse-2026/), merged pull requests tripled in under a year to 220 million a month, commits more than tripled to 7.38 billion a month with most of the growth in the second half, and new repositories doubled to 30.3 million a month. The methodology leans on models as well, with an LLM classifying contributors' profile countries to correct for VPN traffic and a fine-tuned multilingual embedding model assigning repositories to NAICS industry sectors.

Three times the pull requests means three times the reading. LeadDev's piece "AI's time savings are disappearing into code review," [shared on r/LLMDevs](https://www.reddit.com/r/LLMDevs/comments/1xhj52a/developers_saving_10_hours_a_week_with_ai_dropped/) and r/VibeCodeDevs, reports that the share of developers saving 10 or more hours a week with AI fell from 68% to 25% in a year, with the lost time going to fixing generated code. GitHub's product answer is Copilot code review Max, a deeper tier above Lite and Balanced that GitHub says has the highest F1 on ReviewBench for high-severity issues. That is a vendor-reported score on one benchmark, and the test that matters is whether it holds on repositories GitHub did not choose.

The release you can use today is [GitHub Agentic Workflows, now generally available](https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available) on Free, Team and Enterprise plans. An open source project out of GitHub Next, it lets you write an automation such as issue triage, CI failure analysis, doc updates or test writing as a Markdown file, which compiles into standard Actions YAML and runs on your existing runner groups under your existing policies, with Copilot or an agent you bring. The default Copilot CLI engine needs a Copilot license. Safety comes in layers: content passes an integrity filter, agents run read-only by default in a sandboxed container behind the Agent Workflow Firewall, and every proposed change goes through safe-outputs validation plus a separate threat-detection job before it lands. GA adds Actions Runner Controller and Docker-in-Docker support, per-workflow model providers and a model router, Cloud Hypervisor or NVX micro-VM isolation, enclaves against leaks across repositories, and a `gh aw forecast` command, no longer experimental, that projects monthly credit ranges including threat detection. Accenture's testimonial says AI now authors 91% of one team's commits and production errors fell from about 11,000 a day to under 1,000, which is a customer quote rather than a reproducible measurement.

Google's [Gemini 4 Carbon](https://link.mail.beehiiv.com/ss/c/u001.ph_QWNSUqNc4t8_ksAzZPtOnCr0U3hlVEzELSqUWNMYAG3WNicdimvhEF6_um4I3iyNlzidD7BXPMOd-PjPZXDdKzRmXcyzbmvZEBZeqr26kmRFEIUmvIe1g3B2uLkPxZAIeped_1ZELXHDDPRPnCJrCe-vn4AtlYh3ZxsyKi7jmuTR2YKz29OrsC0Pe3gnhStUDdht4bvZ2BDildvm2x2v5ZcUOWvb0thNiHVzED5T3MHNTtAxhL2mIjMrKPmxXGgiQf7DX-rreGaeEDNmhOvILzbV7EJfvXwq4Yua-yblAcFWixSw_tVpWZy3ZUVVdyXC3s7LL9bdabTY8cIOeO454VQMxk2cjSW4bgShEWMbrHNqPw1ujmGF8Tyl74fmkkN1bRgPZawXZchCp9hc-mchV0OXASMxlBxkrs5weEEWpsBqWRCU-bsJdetlDtckDKhJ-Q63LwFmNKQxMzIyU0k7sF3-mbt0yiBsYREL85SlKE7YVTh9g-qc_OcO-Kku8PgJpqCOVW91bjfs_5g2QjysI_HOkgHPOBc80EJvsQVVT3sMjazaCpyXbZulyV3ffOb2OT34ip12HOF9-v1-2xEOVn4oOMhIKPwrnGWAwWYX0tdJbqWDC7kSoWhhWrCwMW2HGU-kfX9wrNyUgFZIm5cRz6KlS8fo6aOT7um3I3fauZx8XMGbP_RRas0HqIUi7ebRqG-kB2z8F4B28y27dKQ/4va/sia1ZUqnT6WH4MUNZRGl1Q/h0/h001.kfM3etxS4Vgr6MLCKZXxGL3OXsaax4MdjE3Lt9PwhaQ) arrived two weeks after Argon and took first place on Artificial Analysis's rebuilt Intelligence Index v5 at 59, one point above Opus 5.5, along with first in Text Arena at 1528. Google is leading with security, posting 88.2% on SEC-bench Pro, 54.8% on ExploitGym and 71.0% on CWE-bench, and the rollout follows that pitch: vetted cyber defenders get it first through the Fairwind Program, with wider developer access promised "as soon as possible." Artificial Analysis lists $4/$20 per million tokens with a 50% launch discount that has no end date, and both the context window and max output are 1M tokens. On coding it does not lead. It scores 59 on the Coding Agent Index in Antigravity CLI against 62 for Claude Code with Opus 5.5, and 61.2% on FrontierSWE, behind GPT-6 Astra, Opus 5.5 and Sonnet 5.5. Its hallucination rate also rose from Argon's 4% to 11%, still the second lowest Artificial Analysis has measured (Opus 5.5 and Astra both sit at 50%), but security teams are the first customers and they pay the most for an invented finding.

The leaderboard Carbon topped is itself new. [AINews' October 28 issue](https://link.mail.beehiiv.com/ss/c/u001.ph_QWNSUqNc4t8_ksAzZPtOnCr0U3hlVEzELSqUWNMbURmwsahxq41L_dHnd3-SQd-ain9bZZkHlIJHAhFryAj_71ENyZ5rT55aNs0sqKbdizVNJ7jGehjvsUsAPO4G6LNFnRAeU8TosA581h__pULDFI1NB3OEjsPfPKFYCZONGnWmsuQauNl5Yo0agMzQeSZUzESrJa6nI4WlQONoWCptHyYlyqXA9fEtMauL02s54bRDN8EzEJBCw-Q1HREF80WmUQlqobPfTm3URugCdyXnmOAwwj6vkh0GXFEQSQm1ZuUDHGhigBmb8n1h04bCwTprDw9F1c4VmcveJ9idpbAQMUoe6C-YDrwkNE4OnO2aHv2l8bkvnmOMb48tXlIQimncysSUv4KpfnwObj9518eujnAGyu_FB3czHGOu0ROKFFu0Tnd9ONyQqpTy-Pzc6-hbBOWgF6WUuGsSA-0WMk6U4v7wY9tAMhXFG8-IOklwM5sjuhc8EUO-UTFP4Jmhg7X5xOoj5O91rUyIrCA1pmRsIk2IincHVESpZXD_EwpqcU0Ui23cVy-OfPPR1tFdkaBdLtFAGfZlDRy7o3xw_ORqnOxppvw4wHvThACG1d1L5tDoDcJ0F1gMLXAk2mV6Vf1bzvI6MhKGNRn3gm5NRQC4CxId2zfEk9X4W_ikae8_0r_LhCivXU2TqGb4zIyqRu4UW7h85C9MbSEPV81ce3DcLxQFLbn-yIjM2dhcMi4qw655m7zsXAJ9AJTq4sDPW/4v9/QdR0ERo0Rmektl27r3ccvA/h0/h001.Qh8_QZp24PgvKqFmRGAhyAOQjFAR9vMvCpOkC6mXO9Q) lays out Index v5: 60% of it runs on private or held-out sets, it adds Cognition's FrontierCode 2.0 and Terminal-Bench-Science, and the gap between the best closed and best open-weights models widened from 3 points to 12. FrontierCode 2.0 gives agents deliberately underspecified prompts and grades whether a maintainer should merge the result, and the top score is 45%. That issue led with Anthropic hiring manager Felix Rieseberg retiring the coding interview: "There's no more point in giving you a little React challenge than there is in quizzing people about assembly; Claude is now better at both." His advice to junior engineers is to chase business impact over the backlog and to build one radical idea into a working prototype over a weekend. The same issue shows how far coordinated agents now reach, with Axiom auto-formalizing the Classification of Finite Simple Groups in Lean: about 50 million lines in 24 days from a proof that spans roughly 15,000 pages across 500 papers, with agents claiming tasks, reviewing each other and merging through GitHub under human guidance, and reportedly fixing hundreds of errata along the way.

Simon Willison also [named a second inflection point](https://simonwillison.net/2026/Oct/28/vibe-game-development/). November 2025 was the inflection for coding agents, and he argues October 2026 is the one for games, with Opus 5.5 now good enough at 3D modeling, music and game design to make something fun. His evidence is four games he enjoys playing, none taking more than four hours of his own time, among them Battle Drones, a real-time strategy game for two to four players where LLMs can play each other in five-second turns, and Emberwick, a 15-minute story whose ending moved him. The prompt that did the most work was "Make it a LOT more fun." He says GPT-6 Astra "isn't quite there yet" on fun and expects OpenAI to catch up by year end. He also addresses the backlash, noting that one game combining AI art, music, writing and code can come across as "four times as insulting," and a Hacker News thread on Valve's response to developers who fear AI slop and clones on Steam shows that worry is live.

Outside the coding stack, NVIDIA's [Nemotron 3.5 Transcribe](https://huggingface.co/blog/nvidia/nemotron-transcribe-granary) reached the Hacker News front page. It is an open-weight 30B mixture-of-experts with about 4B active parameters, covering 40 languages with speaker attribution, translation and audio Q&A. Artificial Analysis measured 2.8% AA-WER, tied with Voxtral Small for best open model, and DeepInfra serves it at 75x real time for $2 per 1,000 minutes, with day-zero vLLM support in BF16, FP8 and NVFP4.

Fusion's independent case rests mostly on one evaluator, so the useful evidence will come from teams that run it against their own repositories and report cost per merged pull request rather than per benchmark task. Carbon's coding numbers were all measured in Antigravity CLI, and how it behaves inside Claude Code, Codex or Copilot stays unknown until Google opens access beyond the Fairwind Program.

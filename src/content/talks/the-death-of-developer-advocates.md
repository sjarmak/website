description: A conference talk on the Agent Advocate, the role that emerges once coding agents write the docs, build the demos, and ship the sample apps that developer advocates used to produce by hand. The Agent Advocate speaks for the agents rather than the humans, treating their failures in real codebases as retrieval and tooling problems instead of evidence the model isn't smart enough. Drawing on agent-native work at Sourcegraph, from measuring how AI tools discover and describe products to turning messy production data into context agents can actually use, it argues that advocacy is shifting from writing the content to building the infrastructure agents depend on.

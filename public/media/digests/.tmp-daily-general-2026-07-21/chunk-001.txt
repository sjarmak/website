That argument had company over the same day and a half. Simon Willison surfaced a Ben Thompson proposal that takes on the distillation fight directly, noting the awkwardness of labs banning distillation against their models while having trained on unlicensed data themselves, and suggesting a path that would help American open models compete. And a piece on frontier lab economics that made the Hacker News front page asked the uncomfortable follow-on question: if K3 is nearly frontier and open, and Qwen 3.8 follows it, what happens to the pricing power of the closed labs, Anthropic in particular, whose margins depend on the frontier staying scarce? Nobody has the answer yet, but the fact that three separate outlets converged on the question within thirty-six hours tells you where the field's attention is.

Now for the day's best artifact. Cursor set a team of agents loose on SQLite's 835-page manual and asked them to rebuild the database from the documentation alone. The swarm produced a replica in Rust that passed one hundred percent of a held-out test suite. Set aside for a moment whether the world needs another SQLite, because the experiment was really about economics, and the number that should stick with you is fifteen. Depending on which mix of models Cursor assigned to the swarm, the cost of getting to the same passing test suite varied fifteenfold. If you run agents at work, that is the finding to carry around, because it means model selection inside a multi-agent system is now a first-order cost lever, the same way instance types are in cloud capacity planning. Which model tier handles planning, which handles the bulk edits, which reviews the output, and what the blend costs per unit of verified work: that is starting to look like a real discipline.

And as if to underline the point, the vendors all shipped agent cost metering the same day. AWS launched CloudWatch coding agent insights, which collects telemetry from Claude Code through the Claude apps gateway without extra configuration and gives engineering leadership a view of what the coding agents are actually doing. GitHub made AI-credit usage visible per billing cycle for every Copilot Business and Enterprise user, and moved credit pools for cost centers into the billing UI where administrators can manage them directly. GitKraken pitched an insights dashboard for agentic workflows the same day. Three vendors converging on agent metering within a day of Cursor publishing a fifteenfold cost spread is less coincidence than the market noticing where the money goes: agent spend is becoming a budget line big enough that somebody in every organization now owns it. If that somebody is you, the practical takeaway is to start tagging agent usage by team and by task now, before the finance conversation arrives, because the Cursor experiment suggests the difference between a well-chosen model mix and a lazy one is not twenty percent, it is an order of magnitude.

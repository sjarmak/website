06 / recovery needs explicit contracts
RETRYThree attempts with bounded exponential backoff
TIMEOUTStage-specific Start-to-Close limits
HEARTBEATThirty seconds for long external calls
IDENTITYStable request IDs and artifact paths

The response journal suppresses a repeated read once the response is stored. Paid or mutating providers must honor the same idempotency key to close the provider-success-before-journal-write gap.

Temporal gives Activities at-least-once execution; external-effect safety stays an application concern

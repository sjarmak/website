# sjarmak.ai

Personal site for Stephanie Jarmak. Astro static site, deployed on Render.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output to ./dist
npm run check    # type-check
```

Node 22 (see `.nvmrc`). Content lives in `src/content/` as Markdown; push to `main` to deploy (`render.yaml`).

Agent workflow and issue tracking: `AGENTS.md`.
